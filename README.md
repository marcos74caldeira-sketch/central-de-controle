# Central de Controle — Multiverso de IA & Ecossistema Gemini

Dashboard operacional e sistema de governança do ecossistema Gemini e Google Drive.

## 🚀 Recursos
- **Acesso direto às 10 Macro-Pastas Oficiais do Google Drive**
- **Catálogo interativo dos 31 Cadernos do NotebookLM**
- **Visão executiva das Verticais e Projetos Estratégicos (Safe2Net, Talent Radar, Aurastudio)**
- **Console de Governança com rotina semanal ativa**
- **Busca universal em tempo real**
- **Modo Claro / Escuro**

## 📦 Como Publicar no GitHub Pages
1. Crie um repositório no seu GitHub (ex: `central-de-controle` ou `marcos74caldeira-sketch.github.io`).
2. Faça o upload dos arquivos `index.html`, `.nojekyll` e `README.md` (ou descompacte este ZIP).
3. No repositório, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e `/ (root)`, depois clique em **Save**.
5. Em instantes, sua Central de Controle estará acessível publicamente via GitHub Pages!
